# 魔法书 v0.1 设计

目标：让阅读中的数学命题在原地成为可以操纵的模型。视觉采用旧报纸：纸色、衬线字、细线分栏、印刷编号、少量墨绿和赭色。沿用“会动的报纸”的概念，独立设计品牌和图形。

第一步先验证阅读引擎，数据层与数学模型独立，方便后续逐段接入书籍。已有四个原创知识块；它们仅是主题演示，不对应尚未核查的原书段落。

数据链路：JSON 知识块 → 浏览器安全文本渲染 → 指定交互组件 → 数学模型 → 结果与解释。正文不会执行输入内容中的代码。实验保持有限图示与无限数学模型的区别；棋盘超过 JavaScript 普通整数精度的结果使用 BigInt。

交互组件：十的幂滑杆、棋盘倍增、旅馆房间映射、有理数去重枚举。每块配置正文、引导、交互、朗读和展开式答案。页面提供动画暂停、系统减少动态效果偏好、打印和键盘访问。

错误处理：内容加载失败显示恢复提示；朗读不支持或失败时给出反馈；切换后台自动暂停棋盘和朗读。不依赖外部服务，因此原型能离线从本地服务器运行。

原书工作链路：核验版本/地区 → OCR → 段落切分 → 稳定编号 → 翻译 → 数学与语言审校 → 多模态知识块映射 → 来源/内容许可审查 → 发布。prepare-book 只建立翻译工作包，不虚构翻译结果。

验证重点：64 格极大整数、旅馆映射的单射性质、有理数枚举的去重、桌面与手机排版、动效控制、加载失败和语音能力降级。全书译文、第一章逐段内容、独立 GIF/视频、在线作者端和云端生成服务均尚未实现。

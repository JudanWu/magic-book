# 连续阅读与图形重绘

`src/reader.js` 读取中文内容 JSON，按章节顺序渲染段落、引用、表格、图形、编者注及脚注。英文底本属于独立校对资料，不送入读者页面。正文保持连续阅读，图形只在原书图示对应的位置插入。

`src/figures.js` 提供 23 类图形组件；每类有独立参数、状态说明和示意限制。它们共享播放、暂停、可访问标签及离屏暂停。所有动画默认静止，触发后才播放，不以自动动画打断长文阅读。

`src/geometry.js` 构造真正用于渲染的网格和数学模型；测试对同一网格数顶点、棱和面，检查欧拉值。汉诺塔测试执行全部移动，逐步检查叠放是否合法。寻宝测试核验不同绞架位置的中点与转弯后路线长度。

立体图采用 SVG 多边形投影和深度排序，无需外部三维库，适合静态托管及打印。这种显示不是完整的 WebGL 渲染器，复杂曲面自交的遮挡效果和光照仍有改进空间。需要精细三维动画时，可以换成 Three.js，同时保留数学模型和控件接口。

人物场景作为普通图片资产独立配置；可由图像生成工具制作并记录来源。数学网格、数量和拓扑配对不由生成图片代替。需要导出讲解视频时，可引入 Manim，再使用 FFmpeg 输出视频或动图；当前版本没有声称包含这些视频。

图 19、20 目前是切口及概念的示意组件，不是严格验证的连续三维变形。编辑需区分原图注、重绘说明、现代校注和原书正文，避免把重绘解释冒充为原作。

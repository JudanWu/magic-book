# 魔法书的阅读原则

用户确认的主旨：保留原书内容，以多模态形式替换原书示意图。

- 读者页面只显示中文译文。英文原文仅用于后台翻译与校对，不显示双语列或英文折叠区。
- 正文按原书段落顺序保留，不用原创讲解、问答、实验卡片或模型概述替代作者正文。
- 插图、示意图与图注有稳定 figureId；动画、动图或可操作示意图放在原图对应位置。
- 图内控件服务于原图所表达的概念，不为每一段增加独立教学活动。
- 原书脚注、译注和编者注有明确区分。老书中的年代数据不悄悄更新进正文。
- 稳定 paragraphId 关联英文底本与中文稿；figureId 关联原图位置、原图注和替代媒体。

当前引擎首页已迁移至正文与图形替换架构。中国大陆独立包的主入口为 index.html，覆盖前三章中文工作稿及 23 幅交互示意；工作稿、图注及复杂拓扑模型仍待审校和精修。早期实验保存在 lab.html，不作为当前首页。

# 魔法书 · Magic Book

让知识在纸上动起来。保留连续中文正文，以交互式重绘替换教材中的示意图。

## 当前版本

v0.2 是纯 HTML、CSS、JavaScript 互动阅读引擎，无外部运行依赖。首页提供三篇原创数学短读，演示线段配对、复数旋转和莫比乌斯带。阅读页不会把每段正文改成实验卡片或问答。

- 按章节连续阅读，脚注跳转，表格与编者注分别呈现。
- 23 种图形组件：棋盘倍增、合法汉诺塔、素数筛、复数寻宝、坐标、正多面体、欧拉证明、带孔多面体、地图邻接与非定向曲面等。
- 立体模型支持调整观察角度。动画默认静止，点击后播放；离开视野或页面后台时暂停。
- 响应式纸页、中文控件、键盘操作、读屏说明和打印样式。
- 复杂拓扑图明确标注示意限制：切口配对图不是已经验证的连续变形，克莱因瓶浸入的自交不代表抽象曲面的交点。

人物场景可作为图片资产插入；数学关系采用确定性程序绘制。当前组件是可操作的示意重绘，尚未全部达到出版插图质量。尚未生成独立 GIF、视频或预录音频。

## 运行与验证

需要 Python 3；测试和打包另需 Node.js 22 或以上。

```sh
npm start
npm test
npm run validate
npm run build
```

打开 http://127.0.0.1:4173 。请通过服务器访问；直接双击会受到模块及 JSON 读取限制。`dist/` 是静态托管目录。`lab.html` 与旧 `src/app.js` 保留早期实验原型，首页已迁移至连续阅读架构。

## 接入内容

`content/reader-demo.json` 展示内容格式。设置 HTML 的 `data-book` 指向 JSON。章节支持 paragraph、quote、heading、table、figure、editor；脚注在章节的 footnotes 中。图形配置的 id 对应 `src/figures.js` 的组件。这是一套固定组件库；新增书籍可能需要增加组件，而不是只替换文字。

```json
{"language":"zh-CN","title":"书名","author":"作者","figures":{"6":{"id":6,"title":"图注"}},"chapters":[{"title":"章节","blocks":[{"type":"paragraph","text":"连续阅读的正文。"},{"type":"figure","id":6}]}]}
```

## 引擎与地区内容分离

全球开源仓库只包含原创演示、原创图形代码和工程文档。英文底本、中文工作译稿、扫描页与地区性图片均在仓库外，不由 MIT 重新授权。

《从一到无穷大》的地区内容工作包已建立前三章中文工作稿及图 1—23 的示意重绘。工作稿尚待独立审校；第三章转载的第三方长引文由标明身份的独立证明说明代替。原图注仍待逐条审核，不能称为出版就绪译本。地区包不在本仓库内。参见[版权核查](docs/rights-research.md)和[阅读原则](docs/reading-principles.md)。
